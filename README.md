# global-sales-data-analysis-python

## Project Description
This project performs an exploratory data analysis on a global sales dataset that includes information about regions, countries, product types, sales channels, order and shipping dates, as well as financial metrics such as revenue and profit.

The objective of the analysis is to identify sales patterns, determine which regions and products generate the highest profitability, and evaluate the performance of different sales channels.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## Analysis Performed
- Data cleaning and preprocessing
- Sales analysis by country
- Sales analysis by region
- Product performance analysis
- Revenue, profit and profit margin analysis
- Sales channel performance
- Exploratory data analysis and data visualization

## Key Insights
The analysis showed that some product categories generate a significant portion of total revenue, allowing the identification of the most important products for the business.

Geographical analysis revealed that certain countries concentrate a large share of revenue and profit. However, higher sales volume does not always imply higher profitability, which was observed when analyzing profit margins.

Regional analysis showed that Sub-Saharan Africa and Europe lead in both revenue and profit, indicating that these regions have a major impact on overall business performance.

Overall, this analysis highlights the importance of evaluating multiple metrics such as revenue, profit and profit margin to better understand sales performance and support data-driven decision making.
